## Что делали по шагам (история)

1. Подключение по SSH к `192.168.50.61`.
2. Установка **goVLESS Lite** (интерактив завис на языке — довели через expect: RU, Lite, TCP, safari).
3. Получены доступы к панели 3X-UI, создан inbound Reality.
4. Настроена короткая subscription-ссылка (`subId`), исправлен `localhost` → публичный IP (`share_addr`).
5. Порт sub `40946` снаружи сначала был закрыт → nginx пробросил sub через **48479**; позже **40946** открыли, подписку перевели на **HTTP** (из-за ошибки сертификата в Happ/INCY).
6. Сделан HTML-портал `/go` с кнопкой «Добавить подписку» и deep link в Happ.
7. Добавлен второй пользователь **friend-fox** со своим subId.
8. Добавлены **Announce / Title / Support** для отображения в клиенте.
9. VPN не работал: **443 закрыт на WAN** → пробросили; handshake всё равно ломался.
10. Reality перенесён на **8443**; dest сменён на **www.microsoft.com**; ослаблен `minClientVer` для INCY.
11. Разобраны режимы клиента: **системный прокси** ≠ рабочий VPN; **TUN** роняет интернет, если туннель мёртвый. `HTTP 503` на `http://89.149.118.186` — это не сайт, открывать IP в браузере не нужно.

## Клиенты (приложения)

Рекомендуемые: **Happ**, **INCY**, Hiddify, v2rayNG.

Как добавить:
1. Вставить subscription URL (`http://…:40946/<subId>`).
2. Обновить подписку после любых правок на сервере.
3. Проверка: [https://ifconfig.me](https://ifconfig.me) должен показать `89.149.118.186`.
4. **Не открывать** в браузере голый `http://89.149.118.186` / `https://89.149.118.186` — там нет веб-страницы.

| Режим | Поведение |
|-------|-----------|
| Системный прокси | Часть приложений через прокси; интернет может «жить», даже если VPN не гоняет трафик |
| TUN | Весь трафик через VPN; если туннель мёртв — пропадает интернет |

## Несколько серверов (15 узлов)

В 3X-UI v3.7 есть **Узлы**.

Схема:
1. Этот сервер = **master** (главная панель).
2. На каждом новом VPS поставить **3X-UI**.
3. На node: **Настройки панели → Учетная запись / Authentication → API Tokens** — создать токен.  
   («Документация API» в меню — только справка, не токены.)
4. На master: **Узлы → Добавить узел** — IP, порт панели, base path, API token.  
   При самоподписанном TLS — отключить строгую проверку сертификата.

## Известные проблемы и решения

| Симптом | Причина | Решение |
|---------|---------|---------|
| Подписка ок, сайты не открываются, 0 B/s | Не проброшен VPN-порт / кривой NAT | Проброс **TCP 8443 → 192.168.50.61:8443** |
| TUN — нет интернета, системный прокси «ок» | Туннель мёртв; системный прокси ходит напрямую | Чинить VPN, не полагаться на системный прокси |
| Happ/INCY: invalid certificate | HTTPS на IP с self-signed | Использовать **http://IP:40946/...** |
| `HTTP ERROR 503` на IP сервера | Нет веб-сайта на :80/:443 | Открывать google / ifconfig.me, не голый IP |
| INCY не коннектится к Reality | Xray 26.x режет старые клиенты | `minClientVer=1.8.0` (уже выставлено) |
| Reality с apple не поднимался | dest недоступен с сервера | dest = **www.microsoft.com** |
